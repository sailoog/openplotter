## Code quality
This project use `autopep8` ensure a good code style quality  

### Install autopep8
#### Debian family
`pip install autopep8`

### Usage
Please run `autopep8 --recursive --max-line-length 4096 --select=E1,W1,W29 --in-place ./` before any commits.
